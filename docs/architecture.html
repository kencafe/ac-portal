Kiến trúc hệ thống website & blog dịch thuật

Next.js trên OpenShift, có Vault giữ token/secret và PostgreSQL lưu bài viết trước & sau khi dịch. Ba môi trường dev / staging / prod theo luồng DevSecOps của OWASP.

Luồng nội dung & dịch thuật Content & translation data flow

Bài từ nguồn RSS được lấy về và lưu bản gốc vào PostgreSQL; worker dịch phía server gọi mô hình AI (token lấy từ Vault) rồi ghi bản dịch trở lại cùng một bản ghi. API công khai chỉ đọc bài đã xuất bản để phục vụ web.

Luồng dữ liệu Bài đã xuất bản (công khai) Secret/token từ Vault

PostgreSQL (CloudNativePG)

Một bản ghi post giữ cả original[] và translated[] nên trạng thái trước/sau dịch nằm cạnh nhau, kèm canonicalUrl, license. Thêm bảng feeds và inbox.

HashiCorp Vault

Giữ API key nhà cung cấp AI, thông tin đăng nhập DB, khoá Public API read-only và webhook secret. App nhận secret qua Vault Agent — không hardcode trong mã nguồn.

Translate Worker

Đọc bản gốc, gọi mô hình theo prompt hệ thống + từ điển thuật ngữ, tôn trọng hạn mức/ngân sách, ghi bản dịch. Nguồn cần xin phép chỉ tạo tóm tắt + link gốc.

Public API + Web

4 endpoint đọc: /posts, /posts/{slug}, /categories, /feed.xml. Next.js SSR phục vụ landing, service, blog; CMS sau xác thực Editor/Admin.

CI/CD DevSecOps trên OpenShift Pipelines OWASP-aligned · Tekton

Mỗi push kích hoạt pipeline Tekton. Quét bảo mật chạy sớm (secret, SCA, SAST) rồi tới build & quét image; DAST chạy trên môi trường staging đang chạy — cổng gate trước khi promote image đã quét sang prod.

Bối cảnh nền tảng AC-portal AC-portal on OpenShift · platform topology

Site này là một app trong AC-portal, chạy trên ba namespace OpenShift theo branch. Một CI hub (EventListener + Pipeline trong ac-portal-dev) build & deploy sang cả ba, dùng chung các dịch vụ nền tảng: Ingress Router, Internal Registry, Vault và lưu trữ Ceph.

Chưa triển khai (backend TODO theo README): ingest RSS, worker dịch phía server, cổng bản quyền, API công khai và xác thực CMS. Frontend hiện chạy trên React state; các mũi tên dữ liệu ở Sơ đồ 1 là kiến trúc mục tiêu để nối backend vào.
